    Reading a Discogs listing Πώς διαβάζεις μια αγγελία

    Sellers grade the record and the sleeve separately with the Goldmine scale: “VG+/VG” means VG+ vinyl in a VG sleeve (πρώτα ο δίσκος, μετά το εξώφυλλο). Tap a grade.

    Also check the seller’s rating and number of ratings, read the condition comment, and remember that orders from outside the EU usually add VAT and customs fees on arrival (ΦΠΑ και τελωνείο).

    The kHz rules, corrected Οι κανόνες για τα kHz, διορθωμένοι

    ≈ 20 kHz
    MP3: aim for about 20 kHz, not 19

    A real MP3 320 reaches about 20 kHz (20–20.5 kHz with the LAME encoder). An MP3 that stops at 19 kHz behaves like a 192 kbps file, and one that stops at 16 kHz is a 128.

    21–22 kHz
    AIFF / WAV / FLAC: about 21–22 kHz

    The ceiling is always half the sample rate: 22.05 kHz for a 44.1 kHz file (most music) and 24 kHz only for a 48 kHz file. A real lossless file stays full up to about 21–22 kHz. One that stops in a flat line at about 20 kHz is very likely an MP3 320 saved as AIFF, so “≥ 20 kHz” is too generous.

    From files to a ready USB Από τα αρχεία σε έτοιμο USB

    1. ImportΕισαγωγήDrag your music folders into Collection.
    2. AnalyseΑνάλυσηLet rekordbox detect BPM, key and beatgrid. Turn on key detection and set a BPM range that suits your music in the analysis settings.
    3. Check the gridΈλεγχος beatgridBeat 1 should sit on the first kick. Fix it in grid edit if it doesn’t.
    4. Set cuesΣημεία cueMemory cues where you mix in and out, hot cues on the drop and the breakdown.
    5. TagΕτικέτεςColours, ratings, comments and My Tags for energy, mood or vocal / instrumental.
    6. Build playlistsPlaylistsBy set or mood: warm-up, peak, closing. Intelligent playlists fill themselves by BPM, key or genre.
    7. ExportΕξαγωγή στο USBPlug in the USB and drag your playlists onto it in Export mode.
    8. Test and back upΔοκιμή και backupLoad a few tracks from the stick, then export the same playlists to a second stick.
